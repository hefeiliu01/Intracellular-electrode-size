# README: Code for Simulation in the manuscript titled "Why intracellular electrodes converge to the microscale"

This repository contains the MATLAB simulation scripts used to generate the data for **Figure 1d**, **Figure 1e**, and the corresponding discussion in the main text of the manuscript.

## System Requirements
* **Software:** MATLAB
* **Tested Version:** MATLAB R2025a
* **Required Toolboxes:** None
* **Operating System:** Any OS capable of running MATLAB (Windows, macOS, Linux)
* **Hardware:** Standard desktop or laptop computer

## Installation Guide
* **Instructions:** No installation required. 
* **Setup:** Download and copy the script files into your MATLAB working directory.
* **Estimated Install Time:** 0 minutes

## Demo & Usage Instructions
The scripts generate their own simulated data internally. No external input data files are required.

### To reproduce Figure 1d and Figure 1e data:
1. Open MATLAB and navigate to the script folder.
2. Run the script `size_to_alpha_disk.m` and `size_to_alpha_hole.m` by clicking **Run** or typing `size_to_alpha_disk` in the Command Window.
3. **Expected Output:** The script will execute the simulation and generate the data corresponding to Figure 1d.
4. **Expected Run Time:** < 1 minute.
